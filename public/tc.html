📋 Syarat & Ketentuan Layanan

1. Sistem Pembayaran & Pembatalan

  • DP Wajib: Pengerjaan dimulai setelah pembayaran DP sebesar 50%.
  • Pelunasan: Sisa 50% wajib dibayar maksimal 3 hari setelah web selesai diuji coba (sebelum serah terima hak akses penuh).
  • Pembatalan: Jika klien membatalkan proyek di tengah jalan, uang DP dianggap hangus.

2. Pembatasan Fitur (Anti Scope-Creep)

  • Website dibangun hanya berdasarkan kesepakatan fitur di awal.
  • Permintaan fitur tambahan di tengah jalan akan dikenakan biaya tambahan per fitur dan penyesuaian deadline.

3. Konten & Materi Website

  • Semua materi (teks, foto produk, logo) wajib disediakan oleh klien.
  • Keterlambatan pengiriman materi akan otomatis memperpanjang deadline tanpa denda bagi developer.

4. Serah Terima & Hak Cipta

  • Setelah pelunasan 100%, seluruh hak akses sistem menjadi milik klien sepenuhnya.
  • Developer berhak mencantumkan tautan kecil di footer website ("Designed by Jaya") sebagai bagian dari portofolio.

5. Aturan Garansi & Kelalaian

  • Garansi 3 Bulan: Hanya berlaku untuk perbaikan bug/error murni dari kode awal. Tidak berlaku untuk tambah fitur baru.
  • Bimbingan Dasar: Klien mendapatkan 1x panduan dasar kelola konten secara mandiri setelah web live.
  • Kelalaian Pengguna: Garansi hangus jika klien/pihak ketiga mengubah kodingan inti atau setelan server tanpa izin. Perbaikan akibat hal ini dikenakan biaya servis tambahan.
